# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/fd14988a-f209-4645-9e13-8ad265ec8909

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) if using client-side features, or run alongside the PageWise FastAPI backend.
3. Run the app:
   `npm run dev`

Live Deployment: https://chat-with-pdf-ai-frontend.vercel.app/
